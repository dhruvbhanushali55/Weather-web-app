# 🌤️ Weather App

A modern, responsive frontend web application that allows users to search for real-time weather conditions, view hourly forecasts, and check key environmental metrics like wind details and air quality.

## 🚀 Features

- **Real-Time City Search:** Quick search bar to fetch current weather details for any specific city.
- **Current Conditions Display:** Clean main dashboard showing location name, condition icon, temperature (°C), weather status (e.g., Sunny), and "Feels Like" temperature.
- **Detailed Weather Metrics:** 
  - Wind speed (`wind-kmph`)
  - Wind gust speed (`wind-guest`)
  - Air Quality Index status (e.g., Moderate)
- **Hourly Weather Forecast:** A structured, chronologically ordered timeline displaying upcoming hourly weather, temperature variations, chance of rain (%), and humidity levels.

## 🛠️ Tech Stack

- **Tech:** HTML, CSS, JavaScript
- **API Integration:** Real-time weather data fetched from a third-party weather API
